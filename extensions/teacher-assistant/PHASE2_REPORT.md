# Phase 2 教材知识库与提前PPTX原型

## 实现

教材上传通过原生Desktop RPC分块传输，核验SHA-256、偏移和重复分块。教材原始文件使用内容寻址的不可变存储，版本保留、写入幂等和修改审计沿用Phase 1业务边界。

PDF、DOCX、PPTX、TXT使用实际文档解析库。来源保留文件页号、幻灯片、段落、表格或行定位。DOCX和TXT不生成虚构页号，目录印刷页码只作待核验提示。规则生成的知识点标为候选，教师在本地界面复核后标记确认。

SQLite FTS5 trigram支持全文检索，短中文词使用转义参数化LIKE。模型语义检索通过公开Hermes LLM接口执行同义词扩展与来源重排，返回已有原文ID，拒绝候选范围外或重复ID。最多两次模型请求，默认关闭，需要教师预先授权和当次确认。来源候选有界，界面明确显示检索范围。

课次记录关联课程、教材不可变版本和原文来源。教材导入新版本后，既有课次继续引用原版本，为逐字稿、教案、课件和试卷提供统一内容依据。

中文Desktop已支持上传、版本选择、解析告警、目录提示、章节修订、候选复核、原文查看与检索。

## 提前可编辑课件验证

测试设计图片由系统真实生图工具根据授课稿概念生成。页面布局由开发者视觉测量，通用PPTX导出器将其重建为32个原生对象，含7个文本框、19个形状、5条连接线及1个9单元格表格。

WPS实际渲染并修改标题、移动圆形、编辑表格单元格，另存后重新读取均保留修改。文件中位图为0。图像的渐变和装饰简化为原生纯色对象，尚未完成像素级视觉还原与自动差异修复。

视觉模型布局适配器已实现图像输入、结构化响应与边界校验，测试使用模拟响应。真实付费视觉模型联调及自动流水线继续在Phase 4–5实施。
