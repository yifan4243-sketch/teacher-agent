# Phase 3 授课逐字稿与原模板教案

## 实现

新增 `teacher_preparation` 原生工具与 `teacher-assistant:teacher-preparation` Skill。Skill通过 `preparation.context` 读取完整课堂语言范例和课次绑定的教材原文，通过 `document.schema` 获取完整正文结构。

Desktop生成按钮创建持久任务，使用公开SDK启动原生Hermes会话和Agent Loop，保持原生上下文、工具发现与Skill机制。会话创建使用canonical接口的稳定request_id，提交使用稳定input_id，任务记录原生会话与结果文档。模型沿用阶段配置或当前Hermes配置，生成前需要教师确认本次模型调用。

逐字稿保存两个完整教学单元，每单元环节时间严格合计40分钟。10分钟休息由导出器单列，实际教学80分钟、日历90分钟。每环节包含可朗读正文、用途、教师动作、学生活动、独立活动分钟、板书及教材来源ID。字符语速与活动时长估算产生时间告警，告警版本需要修订后才可审核。

文档采用追加版本，修订不修改已审核正文。分段修订保留其他环节，版本冲突会拒绝写入。教案关联本课次一个已审核授课稿，教学活动逐一对应所有环节。教师审核只能通过受原生认证保护的界面RPC提交，Agent工具不能审批。

正式导出仅DOCX。授课稿使用可读的中文文档样式，教案填充项目内原始 `教案模板（新）.docx`，保留表格、标签、合并关系、列宽和页边距。原模板固定行高会截断真实长正文，导出时将填充行改为同一最小高度并允许跨页。教学反思保留教师课后据实填写的提示。

导出文件使用不可变内容寻址存储和SHA-256记录。Desktop复用Hermes SDK的原生文件保存能力，保存前绑定来源配置，教师选择目标路径。

## 边界与下一阶段

当前取消保存任务会阻止后续正文入库，停止模型调用仍由原生会话停止按钮执行。跨模块取消、失败与重启恢复的完整验收保留在Phase 9。

Phase 4继续实现正式Slide Blueprint、教学成果关联、可选主题、逐页自动设计图片、重做、缓存与预算。自动视觉布局识别及完整图片转PPTX仍在Phase 4–5范围内。Phase 4–9全部模块继续保留。
