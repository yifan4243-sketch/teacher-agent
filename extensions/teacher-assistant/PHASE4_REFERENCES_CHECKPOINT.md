# 可选参考素材检查点

不使用参考图时继续依据教材、授课稿、教案、目标和页面用途自动设计。本次补齐可选素材，不改变默认主路线，也不要求用户提供固定样式。

## 实现

- schema 12保存不可变参考图、蓝图归属、名称、来源说明、SHA-256和归档状态，以及具体生图任务的素材绑定。
- Desktop支持本地上传、预览、分页选择及归档。静态PNG/JPEG/WEBP最大2MB，边长64–8192且总像素不超过1600万；服务验证真实格式、尺寸和上传哈希。
- 本地上传不会调用模型。预留带参考图的任务另需明确发送授权，记录当前素材ID与哈希。素材归档保留历史，不撤销已经授权的任务。
- 提示词明确参考图仅用于风格，准确教学文字仍来自蓝图。缓存包含参考素材内容，与无参考图的生成分开。
- 执行前校验文件归属、哈希及原生工具当前动态能力声明。不支持参考图片或文件损坏时在attempted之前结束，不记录生图尝试费用。
- 通过原生image_generate的image_url传递本地参考图，沿原生模型路由和配置执行，不增加核心工具、不修改过去会话工具集。
- Agent可查询素材和执行教师已授权任务，上传、归档和发送授权由教师Desktop控制。

## 验证

完整教师回归11文件50项通过。新增2项测试覆盖本地上传预览、图片校验、Agent权限、发送授权、蓝图归属、任务重放、实际原生参数、缓存隔离、归档历史、当前动态能力及文件损坏。结构化页面迁移回归也继续通过。后补的跨蓝图案例定向回归2项通过。

真实Electron/Gateway/SQLite界面流程完成上传、预览、授权预留、取消和归档。数据库与本地文件哈希一致，任务cancelled且attempted=0，参考图外发次数为0。原生参数分发使用离线服务测试，不能描述为真实模型已经按参考图生成。

当前每次选择一张可选参考图，支持整套页面使用同一素材。真实生图及参考风格质量仍待服务配置和费用授权。外部条件不阻塞后续独立开发。
