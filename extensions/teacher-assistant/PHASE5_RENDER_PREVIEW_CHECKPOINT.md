# 实际渲染与设计图对照检查点

页面可通过已安装的本地办公软件渲染为PNG，并与该页面绑定的原始设计图对照。当前实机验证环境为Windows和WPS演示12.0，PowerPoint适配器待对应办公环境验证。

## 实现

- schema 9保存渲染任务、输入PPTX导出版本、办公软件版本、输出文件哈希和像素差异记录。
- 渲染前提交执行认领，重复请求和并发调用复用原任务。失败记录保留，教师可另建任务重试。
- 办公软件打开单独创建的临时PPTX副本，以只读方式渲染，随后关闭该副本。已导出PPTX保持哈希一致。
- 使用公开hermes_platform入口查找PowerShell，沿原生Profile RPC调用，文件位置绑定当前教师配置。
- 原图缩放到实际渲染尺寸后计算RGB平均绝对差，以及任一通道差值大于32的像素占比。差异图保存为独立PNG。
- Desktop同时展示原始设计图、实际PPTX渲染图和像素差异图，提供真实PNG下载及历史任务分页。
- 预览文件以内容哈希保存，读取和下载时核对文件归属及哈希。

## 验证

新增3项测试覆盖像素差异极值、持久任务、并发认领、请求重放、预览、损坏文件、办公软件失败与新任务恢复。便携测试替换Office进程边界，输入和输出使用实际图片及PPTX文件。

完整教师插件8文件42项测试通过。TypeScript和插件校验通过。初次插件校验提示两个私有导入路径，已改为公开入口并补跑定向回归。最终仓库检查和验证凭据保存于phase5-evidence。

真实Electron、Gateway和原生Profile RPC调用WPS 12.0完成渲染，展示三图对照，通过原生保存对话框下载1600×900的实际PNG。下载哈希与SQLite记录一致，渲染前后输入PPTX哈希一致。该技术样例的RGB平均绝对差为18.174525，通道差值大于32的像素占比为0.135718。

技术样例的蓝图文字和部分裁切经过测试修改，输入设计图来自此前系统生图，视觉布局为本机固定模型响应。上述数值反映该样例的实际像素变化，教学内容和图解准确性由教师复核。
