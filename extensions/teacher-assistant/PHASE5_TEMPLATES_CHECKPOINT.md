# 蓝图结构化备用模式检查点

除主线的AI设计图片视觉还原外，现在可从已审核Slide Blueprint生成整套原生可编辑草稿。这个模式不调用生图或视觉模型，不能描述成图片还原成功。

## 实现

- 原生 `teacher_slides`、Hermes Skill和Desktop共用 `slide.deck.from_blueprint`，稳定request_id支持丢失响应重放。
- 使用四种既有主题，生成标题、要点卡片和教学单元/页号/时间文字。可见教学文字来自蓝图，不推断图解或统计数字。此模式目前提供简洁文字卡片布局，复杂关系图继续由主线视觉重建处理。
- 所有页面追加草稿，保护已有视觉页面及审核版本；逐页审核后才能正式导出完整PPTX。
- 页面明确记录 `source_mode=blueprint`，图片和分析ID为空；主线页面为vision。图片来源不明的对象不能加入结构化页面。
- 结构化页面可以实际Office渲染和文字测量，没有原始设计图时只显示渲染图，不生成原图、差异文件或像素准确率。
- schema 11在事务中重建页面表，保留ID、父子版本、审核和时间。迁移前暂时关闭SQLite外键动作，提交前核对全部外键，完成后恢复强制校验；任何失败均回滚。

## 验证

3项新增测试覆盖原生Agent工具创建、幂等、审核门槛、真实多页PPTX、准确文字和0位图、重复生成保护审核成果、渲染无虚假差异、无来源图片拦截，以及schema 10带完整关联数据升级和失败回滚。完整教师回归10文件48项通过。

真实Electron、Gateway、SQLite与WPS 12.0通过：界面生成8页草稿，第一页保留旧主线v3审核成果并追加v8；真实渲染取得3个文字区域，超框和缺测均为0；界面逐页审核8页，原生下载整套PPTX，重读确认8页且无位图，下载SHA-256与数据库一致。

测试采用本机脚本模型生成此前教学正文和蓝图，备用生成本身为确定性程序，WPS渲染及文件下载真实执行。日志、收据、课件和实际PNG见 `phase5-evidence/blueprint-templates`。真实模型教学质量、PowerPoint环境及复杂视觉布局继续待验证。

首次迁移测试暴露SQLite延迟外键计数不能安全完成带关联数据的换表，已采用提交前foreign_key_check的标准重建流程，并验证失败时旧schema和数据保持完整。最初便携渲染用例漏设Office边界替身，已补齐；未将该失败当作真实Office故障。
