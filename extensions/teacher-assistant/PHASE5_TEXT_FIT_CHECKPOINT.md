# 实测文字字号适配检查点

本次加入文字框和原生表格的字号适配，属于 Phase 5 自动布局修复的一部分。完整视觉修复、结构化备用模式及 Phase 6–9 继续实施。

## 实现

- schema 10 保存修复草稿、来源渲染任务、最小字号及具体变更。修复追加新草稿，保留此前已审核版本。
- WPS / PowerPoint 对实际文件采集文字内容宽高、框内可用宽高和表格单元格测量，每页最多检查500个区域，缺测数单独显示。
- 检查同时遵守原定文字框和单元格尺寸。WPS可能自动撑高表格行，不能把扩张后的可用高度当作符合原版式。
- 按超框比例缩小字号，保留4%余量，0.5点以内误差不算超框。默认最小字号为32原图像素，教师可以调整为8–160；达到下限时明确记录，不承诺自动解决所有超框。
- Desktop可依据测量创建新版本，并重新实际渲染。若后续预览失败，新草稿仍可查看和重新渲染，错误通过原生通知显示。
- 旧预览仍可读取；缺少测量时要求重新渲染。旧页面有新版本时禁止依据过时测量追加修复。

## 验证与范围

教师测试覆盖文字框和表格比例、可读性下限、Office自动撑高行、缺测、非有限数值、审核保护、幂等、旧版本冲突与旧预览兼容。真实Desktop回归使用本机WPS 12.0执行标题和表格超框、修复及再次渲染；最终执行收据和日志保存在 `phase5-evidence/text-fit`。

最初真实表格用例失败，原因是Office自动撑高行掩盖了版式缺陷，已修正原定尺寸约束。另一次便携测试暴露二进制浮点向下取整边界，验证改为允许保守的0.1像素差异，未放宽实际超框检查。

生图和视觉布局服务在集成测试中使用本机模拟服务；WPS打开、渲染、文字测量和SQLite版本保存均真实执行。该结果不能替代真实模型视觉还原质量验收。PowerPoint适配器仍待对应环境验证。
