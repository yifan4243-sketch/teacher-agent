# Phase 6：学期 月度 每周计划文件导出

学期计划现在支持DOCX、XLSX和PDF，可以导出全学期或当前月份、ISO教学周。授课逐字稿和正式教案的最终导出仍然只有DOCX。

## 实现

- schema 15保存计划ID、范围、格式、具体内容指纹、文件路径、SHA-256和导出时间。内容相同可复用经过哈希检查的文件。
- 文件依据选定的不可变计划版本生成，标注未发布、已发布或历史状态。发布状态或课程名称变化时内容指纹改变，保留以前的导出文件。
- 表中保留真实课次号、日期、时段、教材章节、教学/休息分段及独立考核分钟。所选范围的教学、考核、日历分钟由程序计算。
- 文件明确不包含后续实际调课和完成记录，实际安排在课表中查看。
- DOCX采用横向A4、原生表格及重复表头；XLSX提供筛选、冻结窗格、列宽、自动换行和打印设置；PDF支持中文、自动分页和重复表头。
- XLSX将所有外部文字明确写为字符串，包含以等号开头的标题，防止被当作公式执行；数字单元格仍为数值。
- Desktop通过原生文件对话框下载，连续RPC及保存过程保留当前Profile。读取导出时检查当前配置文件归属和内容哈希。
- 实现使用Hermes已有python-docx、openpyxl、reportlab、pypdf依赖，没有新增第三方框架，也没有复制专有Skill实现。

## 实际验证

完整教师回归14文件57项通过，新增2项覆盖三种真实文件、课程/教材与版本内容、全学期/周/月范围、缓存、发布/历史状态、长标题、公式文字、损坏文件，以及授课稿/教案DOCX限制。版式修改和后补状态/范围案例的定向回归2项通过。

真实Electron/Gateway/SQLite通过原生下载三种9课次的全学期文件及2课次周计划XLSX。重读核对教学640分钟、考核120分钟、文件哈希以及XLSX无公式。

随后通过同一生产生成器和真实Plugin RPC创建明确的虚构校历样例，WPS文字12.0与WPS表格12.0实际打开、打印渲染并关闭各自样例。最终DOCX为1页、XLSX为2页、原生PDF为1页；逐页渲染检查中文、表头、教学/休息、分页和末行，未见截断。WPS操作前后原始DOCX/XLSX哈希保持一致。

首轮视觉检查发现Word默认标题蓝线及PDF末条考核记录被挤入新页。已修改生成器清除标题边框、加宽首列并调整PDF单元格留白，重新生成和渲染后确认修正。XLSX保留5条及4条课次两页排版，没有缩小成不可读的一页。

证据位于 `phase6-evidence/plan-export`。原始QA及WPS诊断保留于 `E:\TeacherAgentData\phase6-evidence`。样例内容为测试数据，计划计算、文件生成及Office渲染没有调用模型。此前Agent正文与图片集成仍使用本机模拟服务，真实模型质量待授权验证。
