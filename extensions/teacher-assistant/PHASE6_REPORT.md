# Phase 6 实际执行报告

## 功能范围

本阶段完成学期、月度和每周计划、实际课表、调课、教师进度、文件导出、提醒与待办。详细增量证据分别保存在规划、课表、导出和提醒检查点中。本报告补充人工章节进度调整、课间与下课提醒、PPT准备状态及阶段回归。

计划按教师配置的学期日期、每周时段、停课日期及真实教材章节计算。章节难度控制自动课次分配，练习、复习及考核分别配置。常规课次保持40分钟教学、10分钟休息、40分钟教学，实际教学80分钟、日历跨度90分钟。考核单独计算时长。

## 本次开发

- 支持逐课次修改教学内容、重新分配章节、上移和下移教学、练习、复习与考核。完整内容序列需要覆盖所选章节，课次数及用途数量与计划一致，日期冲突仍由原有校验处理。
- 人工调整保存为新版本。重新计算可保留人工内容，教师也可选择按难度重新分配。旧计划、旧发布快照及导出文件保留。
- 发布复用可对应的课次。已记录的调课与实际授课分钟会继续保留，无法对应时原有一致性校验会报告冲突。
- 课间与下课提醒依据实际课表的分段起止时间计算，和大课共用事件关联。两种提醒默认关闭，可分别配置提前分钟。
- 备课提醒与课表编辑界面读取关联课次的实际审核状态，显示授课稿、教案和指定审核蓝图的PPT页面准备情况。
- schema 17在提醒设置中增加课间及下课提前分钟。已有schema 16数据按原顺序迁移，旧计划及旧提醒设置的幂等回执继续可重放。
- 原生Teacher Workspace Skill补充计划内容调整、自然语言待办任务的日期解析、提醒记录及备课状态操作说明。Agent通过既有`teacher_records`工具保存和查询数据。
- 计划结果表增加列宽、留白、长内容换行及窄窗口横向滚动。

功能通过独立教师扩展、原生Skill、工具、调度器和Desktop SDK交付。

## Windows运行条件与资源

教师可在提醒与待办页启用通知，并安装或修复当前Windows用户的后台任务。任务每分钟启动短时Python检查，使用交互登录令牌和普通权限调用Hermes原生无模型cron。重复实例由Windows忽略，单次任务限制为4分钟。桌面关闭后的真实触发与发送已通过独立Profile验证，测试任务随后停用。

后台需要有效Hermes运行环境及当前用户登录。关机或退出登录期间暂停，恢复后按补发窗口处理。API接受和系统历史记录可查询，阅读情况由用户确认。并行回归期间一次空闲检查的实测墙钟时间为18.56秒，峰值内存尚未测量。
