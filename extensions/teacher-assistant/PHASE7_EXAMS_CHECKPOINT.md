# Phase 7 命题与试卷模块

## 实际实现

schema 19新增命题方案、试卷版本、题目顺序关联、原生命题任务和导出记录。命题方案保存课程、确定教材版本、章节、指定知识点、已授范围、题型数量、难度数量、整数总分、考试时长、最低知识点覆盖率及学生学习水平。

章节包含子章节。范围取教材、章节、知识点和已授进度的交集。已授范围使用当前发布课表中的已完成教学课次，优先采用教师绑定的备课原文，保存课次ID和版本快照。新进度通过修订方案重新取值。

试卷固定引用每个题目的确定版本和顺序。保存时校验课程与教材、原文范围、题型数量、难度数量、总分、知识点覆盖率及重复题目。相同题目根版本和归一化后相同的题干均会报告重复。分值沿用百分之一分的整数。知识点覆盖率采用覆盖的唯一知识点数占方案范围知识点数的比例，校验使用整数计算。难度数量留空时由选题或命题过程决定。

教师工作台新增考试命题页，可以编辑和修订命题方案，从题库组卷、调整顺序、保存试卷版本，逐题查看教材证据及评分细则、审核题目和试卷。组卷可查询最近已审核版本，历史试卷保留各自题目版本、顺序和审核记录。

生成入口沿用Hermes原生会话、技能、teacher_assessment工具和持久workflow。配置使用已有exams阶段模型。教师勾选本次模型调用后启动，保存原生会话ID，状态变化刷新试卷列表。任务取消会阻止后续试卷保存，模型请求可通过原生会话停止按钮结束。待审核的同方案试卷修订会同步更新任务审核对象。

正式学生版及教师版支持DOCX和PDF，采用A4中文试卷排版。学生文档由题干、选项、分值和作答空间构建。教师文档包含参考答案、解析、简答题Rubric和教材定位。正式导出需要教师审核每个题目版本及试卷版本。导出缓存按确定试卷版本、受众和格式保存，下载校验配置档案内文件归属及SHA-256。

授课稿和正式教案继续通过既有DOCX流程交付，常规教学课次按40分钟教学、10分钟课间、40分钟教学执行。考试使用方案中独立配置的考核时长。

## 测试与问题修复

教师插件完整回归17文件72项通过，文件自动重试关闭。命题定向4项覆盖五类题型、精确组卷约束、覆盖率、跨课程输入、版本并发、教师审核边界、四种导出组合、文件损坏、任务取消与数据库持久性。最终补充定向验证包括教师修订后的任务审核对象。

真实Electron、Gateway、Agent循环、原生Skill及SQLite完成命题和审核链路。模型使用本机脚本服务，按真实工具调用保存题目、组卷和推进任务。教师通过界面审核后下载学生与教师版DOCX/PDF，重读文件确认学生版隔离答案、解析和评分细则。教师手工调整题目顺序并保存、审核v2，v1仍可查询且保留原题序。新增命题和此前工作台端到端两项回归通过，最后扩展手工组卷验证的命题项再次通过。

初次新增命题端到端测试发现，Agent已保存试卷，但界面仍显示命题任务pending且列表未刷新。已加入生成状态轮询、状态变更后的试卷查询失效及手动刷新入口，重测通过。仓库检查发现测试模块的导出名称未排序，已修正。

已将原生Desktop生成的DOCX通过本机WPS实际导出PDF，与直接生成的PDF分别渲染检查。首次DOCX渲染发现WPS对标题样式添加装饰线，已显式清除相应段落边框。中文PDF采用项目既有STSong-Light CID字体方案，本机Poppler使用SimSun替换进行渲染。

使用既有schema 18的非空测试数据库副本执行19迁移，2门课程、1班、1名虚构学生、6个题目版本、6个教学文档和3个学期计划的全部记录哈希保持一致，外键校验通过。源数据库以只读方式打开。

TypeScript、插件验证与仓库15项检查通过。实际证据与最终日志位于phase7-evidence/exams，原始文件保存在E盘phase7-evidence/exams目录。全部资料为虚构测试内容，本轮外部付费模型调用0次。
