# Phase 7 题库基础模块

## 实际实现

- schema 18保存题目版本、教材原文关联和知识点关联，包含课程、固定教材版本、答案、解析、难度、分值及教师审核记录。
- 支持单选、多选、判断、填空和简答。选项标识与答案匹配，填空位置与接受答案逐一对应，简答题评分细则的合计分值与题目一致。
- 分值使用百分之一分的整数保存，2.50分保存为250。教师界面提供分值输入，答案与评分要点使用结构化表单，保留正文中的竖线、换行和自定义选项标识。
- 题目修订追加版本。教师可切换同一课程中的教材版本，并重新选取对应原文和知识点。每个题目版本保留各自来源与审核记录，旧草稿可以单独审核。
- 题库支持教材版本、包含子章节的章节范围、题型、难度、审核状态和题干检索。题目、来源、知识点与历史版本均可分页。
- 已通过的旧版本可以继续查询，新的草稿具有独立状态。题干经Unicode及空白归一化后进行重复提示，返回实际重复题目的标识。
- 原生`teacher_assessment`工具和Teacher Assessment Skill已注册。`question.schema`提供题目数据结构，`question.save`保存草稿，查询和修订均通过既有教学服务。教师在Desktop执行审核。
- Desktop新增可直接操作的题库，包括五类题型、教材依据、知识点选择、版本切换、修订、审核和具体的输入校验提示。
