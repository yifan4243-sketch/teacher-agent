# Phase 7 答卷图片识别与校对

## 已实现

schema 22新增原始答卷文件、分块上传、页面缓存、识别预算、页面任务及校对答卷来源。支持PNG、JPEG、WEBP和1至200页PDF，单文件最大50MB。页面通过现有PDFium与Pillow真实渲染，原件及每页文件采用配置档案归属和SHA-256检查。复用已有上传分块契约，教材和答卷共用前后端上传实现。

教师先选择已审核试卷及已选课学生，上传文件、设置预算并授权页面外发，再按页预留和执行任务。转录通过公开的ctx.llm.complete_structured接口调用批改阶段视觉模型，输入包含题号、题型、题干、选项和实际页面。答案、解析及Rubric在转录请求中省略。模型结果验证题目范围、题型、选项与空位数量，并保留原文、置信度、说明和真实输入页面哈希。

外部调用前持久认领任务并记录计费尝试，模型调用期间释放数据库写锁。重放同一任务返回已有状态。缓存绑定文件、页号、模型与转录版本，默认模型另绑定原生主模型配置指纹。默认路由变化后旧排队任务在调用前返回设置变化提示，教师可取消后重新预留。强制重做另建任务。取消保留状态及费用，执行中的取消需确认可能计费。模型信任拒绝和页面损坏在计费事实中分别处理，缺少回执时使用教师估算记账。

合并按页序进行，每页选择一份成功结果。相同结果可复用，简答跨页不同文本连接并提示核对，其他题型的冲突答案清空待校对。缺题、低于80%置信度及未定位作答均提示人工复核。保存时服务端重新计算复核条件，答案复用既有答卷校验与版本事务，并记录教师及识别来源。已有答卷的最新版本由合并结果返回，过期写入仍由版本校验阻止。

Desktop在既有答卷学生与试卷选择下提供上传、逐页预览、预算授权、任务执行、取消重做、分页选择、逐页原文及置信度、五类答案校对和保存。之后进入已有评分、教师发布、成绩历史及报告下载流程。批改DOCX/PDF增加原件文件名、页号及SHA-256。
