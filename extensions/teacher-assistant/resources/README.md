## 授课稿参考资料

完整授课逐字稿范例已按用户提供的正文保存。后续授课稿 Skill 将通过清单读取该文件。

工业机器人范例用于提取教学语言、互动和节奏。课程内容由所选教材和课程配置确定。

范例的四个环节分别标注约 5、7、2、1 分钟。这些时间保留为原始参考信息。正式课程执行统一的 40+10+40 分钟规则。范例中的教材页码、图号和学科事实需要对应原教材核验后才能作为知识来源。

## 已批准约束

- 正式授课逐字稿和正式教案仅导出 DOCX。
- 默认一次课为 40 分钟教学、10 分钟休息、40 分钟教学。
- 日历跨度为 90 分钟，教学活动合计 80 分钟。
- PPT 图片转可编辑 PPTX 的技术验证提前进行，检查原生文字和对象的真实编辑能力。
- 正式批改和成绩发布前建立学生身份与课程关联。
- 正式版交付继续覆盖已批准的全部 Phase 0–9。
